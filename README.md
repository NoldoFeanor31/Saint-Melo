# Versículo Diario Bot

Un bot de Discord que envía un versículo diario en español latinoamericano.

## Instalación

1. Clona este repositorio:
    ```bash
    git clone https://github.com/tu-usuario/tu-repo.git
    ```

2. Crea un entorno virtual y actívalo:
    ```bash
    python -m venv venv
    source venv/bin/activate  # En Mac/Linux
    venv\Scripts\activate     # En Windows
    ```

3. Instala las dependencias:
    ```bash
    pip install -r requirements.txt
    ```

4. Crea un archivo `.env` con el siguiente contenido:
    ```env
    TOKEN=tu_token_aqui
    CHANNEL_ID=tu_id_de_canal_aqui
    ```

5. Ejecuta el bot:
    ```bash
    python bot.py
    ```

## Despliegue

Este bot puede ser desplegado en Render o cualquier plataforma que soporte Python.
